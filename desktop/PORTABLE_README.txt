Vtubecord portable edition
==========================

Run Vtubecord.exe. No Python, Node.js, or browser installation is required.
The application starts its bundled backend without opening a terminal window.

Writable configuration, chat history, downloaded models, and logs are kept in:
%LOCALAPPDATA%\Vtubecord

The resources folder contains the bundled backend and updater. Run
resources\VtubecordUpdater.exe while Vtubecord is closed to check for the
latest GitHub release and install it. The updater targets:
https://github.com/levox00/Vtubecord

Model weights are intentionally not included in this archive. Download them
from the Vtubecord settings after launch.
