# Character Trait Library

This file is intentionally human-editable. The YAML front matter powers the
guided picker; the headings below document the same options for people editing
profiles by hand. Add a trait with an `id`, `label`, `category`, `description`,
and `guidance` to make it available after refreshing the profile editor.

## Personality traits A–Z

The built-in traits are alphabetized in the front matter so the picker can
search them quickly while this section remains a readable reference.

## -dere archetypes

The `-dere` options are deliberately written with consent and safety guidance.
They describe fictional conversational flavor, not permission to control,
threaten, or mistreat a user.
